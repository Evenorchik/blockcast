# Text Typing Simulator

Симулятор набора текста с интерфейсом мессенджера в стиле iMessage.

## Возможности

- 📱 Интерфейс в стиле iMessage с темной темой (1:1 копия)
- ⌨️ Полноценная iOS клавиатура с анимацией нажатий клавиш
- 🎬 Реалистичная симуляция набора текста символ за символом (как запись экрана)
- ✨ Визуальные эффекты нажатия клавиш в реальном времени
- 📊 Статусы сообщений: Delivered и Read
- 💬 Индикатор набора текста (typing...)
- 🤖 Автоматические ответы от собеседника с рандомными сообщениями
- ⚡ Настраиваемая скорость набора (50-500 мс между символами)
- 🎯 Автоматическая отправка сообщений
- 🎨 Адаптивный дизайн

## Использование

1. Откройте файл `text-typing-simulator.html` в браузере
2. В панели управления введите текст, который хотите набрать (например: "I love you")
3. Настройте скорость набора с помощью ползунка (по умолчанию 100 мс)
4. Нажмите кнопку "▶ Начать набор"
5. Наблюдайте, как текст набирается символ за символом в реальном времени

## Настройки

- **Текст для набора**: Введите любой текст, который нужно симулировать
- **Скорость набора**: От 50 мс (быстро) до 500 мс (медленно) между символами
- **Показывать клавиатуру iOS**: Включить/выключить отображение анимированной клавиатуры
- **Показывать курсор**: Визуальный индикатор позиции набора
- **Автоматически отправлять**: Сообщение отправится автоматически после завершения набора
- **Автоответы от собеседника**: Второй человек автоматически отвечает рандомными сообщениями

## Реалистичные эффекты

### Статусы сообщений
- При отправке сообщения появляется статус **"Delivered"**
- Через 1 секунду статус меняется на **"Read"** (прочитано)
- Статус отображается только под последним отправленным сообщением
- При отправке следующего сообщения статус предыдущего удаляется (как в настоящем iMessage)

### Автоматические ответы
После отправки вашего сообщения:
1. Через 2 секунды появляется индикатор **typing...** от второго человека
2. Через 2-4 секунды (случайная задержка) приходит ответное сообщение
3. Ответы выбираются случайным образом из 3 вариантов:
   - "Aww that's sweet ❤️"
   - "Can't wait to see you 😊"
   - "Miss you too babe 💕"

## iOS Клавиатура

Симулятор включает полноценную iOS клавиатуру с темной темой:
- Темная тема как на iPhone (темно-серые клавиши на черном фоне)
- QWERTY раскладкой (английская)
- Анимацией нажатия клавиш в реальном времени
- Всплывающими подсказками при нажатии
- Автоматическим нажатием Shift для заглавных букв
- Визуальной обратной связью как на настоящем iPhone

## Кнопки управления

- **▶ Начать набор**: Запускает симуляцию набора текста
- **⏹ Остановить**: Останавливает набор текста
- **🗑 Очистить чат**: Удаляет все отправленные сообщения
