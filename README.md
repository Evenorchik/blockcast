# Text Typing Simulator

Симулятор набора текста с интерфейсом мессенджера в стиле iMessage.

## Возможности

- 📱 Интерфейс в стиле iMessage с темной темой
- ⌨️ Реалистичная симуляция набора текста символ за символом
- ⚡ Настраиваемая скорость набора (50-500 мс между символами)
- 🎯 Автоматическая отправка сообщений
- 💬 История сообщений с анимацией
- 🔄 Индикатор набора текста
- 🎨 Адаптивный дизайн

## Использование

1. Откройте файл `text-typing-simulator.html` в браузере
2. В панели управления введите текст, который хотите набрать (например: "I love you")
3. Настройте скорость набора с помощью ползунка (по умолчанию 100 мс)
4. Нажмите кнопку "▶ Начать набор"
5. Наблюдайте, как текст набирается символ за символом в реальном времени

## Настройки

- **Текст для набора**: Введите любой текст, который нужно симулировать
- **Скорость набора**: От 50 мс (быстро) до 500 мс (медленно) между символами
- **Показывать курсор**: Визуальный индикатор позиции набора
- **Автоматически отправлять**: Сообщение отправится автоматически после завершения набора

## Кнопки управления

- **▶ Начать набор**: Запускает симуляцию набора текста
- **⏹ Остановить**: Останавливает набор текста
- **🗑 Очистить чат**: Удаляет все отправленные сообщения

## Примеры использования

### Пример 1: Простое сообщение
```
Текст: "Hey babe"
Скорость: 100 мс
```

### Пример 2: Быстрый набор
```
Текст: "Quick update"
Скорость: 50 мс
```

### Пример 3: Медленный, реалистичный набор
```
Текст: "About that leaky sink"
Скорость: 150 мс
```

## Технические детали

- Чистый HTML/CSS/JavaScript (без внешних зависимостей)
- Адаптивный дизайн для различных экранов
- Плавные анимации и переходы
- Реалистичная вариация скорости набора (±25 мс)

## Разработка

Проект создан как часть blockcast для демонстрации симуляции набора текста в реальном времени.
